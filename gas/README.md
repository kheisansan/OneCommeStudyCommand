# 共有辞書 (Google Spreadsheet + Google Apps Script)

教育辞書プラグインの「共有辞書」機能のサーバー側です。
非公開のGoogle Spreadsheetをデータベースとして使い、Google Apps Script (GAS) のウェブアプリを唯一の公開窓口にします。

- 辞書の取得は誰でも可能 (公開データ)
- 投稿は誰でも可能だが、必ず `pending` (承認待ち) として保存される
- スプレッドシートのオーナーがメニュー操作で承認すると、初めて辞書に公開される

## セットアップ

1. Google Driveで新しいスプレッドシートを作成します (非公開のままでかまいません)。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. エディタの `コード.gs` の内容をすべて削除し、`Code.gs` の内容を貼り付けて保存します。
4. エディタ上部の関数選択で `setupSharedDictionary` を選び、「実行」します。
   - 初回は権限の承認を求められるので許可します。
   - `dictionary` / `submissions` / `blocked-users` / `settings` の4シートが作成されます。
5. モデレータ機能を使う場合は、登録用パスワードを設定します。
   - Apps Scriptエディタの「プロジェクトの設定」(歯車アイコン) →「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ名: `MODERATOR_PASSWORD` / 値: 任意のパスワード
   - このパスワードはスプレッドシートには保存されず、オーナーのGAS環境にだけ存在します。
6. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
   - 説明: 任意 (例: `shared-dictionary v1`)
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
7. デプロイして表示される **ウェブアプリURL** (`https://script.google.com/macros/s/…/exec`) をコピーします。
8. プラグインの管理画面「共有辞書」の「共有辞書URL」へ貼り付けて保存します。

> [!IMPORTANT]
> コードを修正した場合は「デプロイ」→「デプロイを管理」から既存デプロイの**バージョンを更新**してください。「新しいデプロイ」を作るとURLが変わり、利用者全員のURL再設定が必要になります。

## 運用 (オーナーの操作)

スプレッドシートを開くと「共有辞書管理」メニューが表示されます (表示されない場合は再読み込み)。

### 投稿の承認・却下

承認方法は2つあり、どちらでも同じ処理が行われます。

**方法1: statusセルを直接変更 (推奨)**

`submissions` シートの `status` セルをプルダウンで `approved` または `rejected` に変えるだけで、自動的に処理されます (`setupSharedDictionary` が設置するonEditトリガーが実行します)。

**方法2: メニューから一括処理**

1. `submissions` シートで対象の行を選択します (複数行可)。
2. 「共有辞書管理」→「選択行を承認」または「選択行を却下」を実行します。

承認時の処理は投稿の `type` によって異なります。

- `add` (追加申請): `dictionary` シートへ転記されます
- `remove` (削除申請): `dictionary` シートから該当単語の行が削除されます

いずれも辞書バージョンが自動で上がり、利用者の次回取得から反映されます。処理済みの行 (`reviewedAt` が入っている行) は二重処理されずスキップされます。

### モデレータ (別の配信者による承認)

信頼できる別の配信者に承認・却下を任せられます。

1. オーナーがスクリプトプロパティ `MODERATOR_PASSWORD` を設定します (セットアップ手順5)。
2. パスワードをDMなど安全な方法でモデレータへ伝えます。
3. モデレータは自分のプラグイン管理画面「共有辞書」→「モデレータ」でパスワードと表示名を入力して登録します。
4. 登録が済むと、モデレータは次の方法で承認・却下できます。
   - 管理画面の「承認待ちの申請」一覧のボタン
   - 自分の配信チャットで `共有承認(単語)` / `共有却下(単語)` (配信者本人のコメントのみ有効)

仕組み: パスワードはあくまで登録時の合言葉で、認証に使われ続けるのはモデレータのプラグインが持つ匿名トークンです (`moderators` シートに記録)。そのため:

- **失効**: `moderators` シートから該当行を削除すれば、そのモデレータは即座に権限を失います。
- **パスワード変更**: スクリプトプロパティを書き換えても、登録済みモデレータには影響しません (新規登録だけが新パスワードになります)。
- 誰がどの申請を処理したかは `submissions` シートの `reviewedBy` 列に残ります (シート上の操作は `owner`)。

オーナー自身もチャットから承認したい場合は、同じ手順で自分のプラグインをモデレータ登録してください (シート上の操作には登録は不要です)。

### 迷惑な投稿者のブロック

`submissions` シートで対象の投稿の行を選択し、「共有辞書管理」→「選択行の投稿者をブロック」を実行します。
その投稿者のトークンからの投稿は以後拒否されます (`blocked-users` シートで管理)。

> [!NOTE]
> トークンはプラグインが自動生成する自己申告のIDで、GASからは接続元IPを取得できません。ブロックやレート制限は嫌がらせの抑止程度と考え、公開の可否は承認ゲートで守る前提です。

### 辞書を直接編集した場合

`dictionary` シートを直接編集 (読みの修正、`enabled` をFALSEにして一時停止など) した場合は、「共有辞書管理」→「辞書バージョンを更新 (手動編集の反映)」を実行してください。利用者側のキャッシュが次回取得で更新されます。

## settingsシート

| key | 意味 | 初期値 |
| --- | --- | --- |
| `dictionaryVersion` | 辞書のバージョン。承認時に自動で増える | 1 |
| `maxSubmissionsPerHour` | 同一トークンからの1時間あたり投稿上限 | 5 |
| `maxPendingTotal` | 承認待ちの総数上限 (超えると投稿を受け付けない) | 200 |

## API仕様

すべてJSONを返します。GASの仕様上、エラーもHTTP 200で返るため、本文の `ok` で判定します。

### GET `?action=dictionary[&version=N]`

承認済みで `enabled` な項目の一覧を返します。`version` が現在のバージョンと一致する場合は `{"ok":true,"version":N,"notModified":true}` を返し、転送量とシート読み取りを節約します。応答は5分間キャッシュされます。

```json
{"ok":true,"version":3,"entries":[{"id":"…","word":"github","reading":"ギットハブ","category":"IT","author":"alice","updatedAt":"2026-08-07T00:00:00.000Z"}]}
```

### GET `?action=submissions&token=TOKEN`

そのトークンの投稿履歴 (最新50件) を返します。

### GET `?action=pending&token=TOKEN` (モデレータのみ)

承認待ちの申請一覧 (最大200件) を返します。トークンが `moderators` シートに登録されていない場合は `NOT_MODERATOR` を返します。

### POST モデレータ登録

```json
{"action":"registerModerator","password":"…","name":"mod-alice","token":"…"}
```

スクリプトプロパティ `MODERATOR_PASSWORD` と一致すればトークンを `moderators` シートへ登録します。拒否コード: `PASSWORD_NOT_SET` (プロパティ未設定)、`INVALID_PASSWORD`、`BLOCKED`。

### POST 承認・却下

```json
{"action":"review","word":"github","decision":"approve","token":"…"}
```

`decision` は `approve` / `reject`。正規化した単語が一致する承認待ちの申請を1件処理します。拒否コード: `NOT_MODERATOR`、`NOT_FOUND` (該当する承認待ちがない)。

### POST (本文はJSON)

追加申請:

```json
{"action":"submit","type":"add","word":"GitHub","reading":"ギットハブ","category":"IT","authorName":"alice","token":"…"}
```

削除申請 (プラグインの「共有忘却」コマンドから送信されます):

```json
{"action":"submit","type":"remove","word":"GitHub","token":"…"}
```

成功時は `{"ok":true,"submissionId":"…","status":"pending"}`。
拒否時は `{"ok":false,"code":"DUPLICATE"}` のように理由コードを返します。

主な拒否コード: `DUPLICATE` (追加: 辞書または承認待ちに同一単語 / 削除: 同一単語の削除申請が承認待ち)、`NOT_FOUND` (削除対象が辞書にない)、`RATE_LIMITED`、`QUEUE_FULL`、`BLOCKED`、`INVALID_WORD` / `INVALID_READING` / `INVALID_CATEGORY` / `INVALID_AUTHOR` (空・文字数超過・禁止文字)、`INVALID_TOKEN`、`BUSY` (ロック取得失敗)。

## 制限値 (プラグイン側と共通)

- 単語: 正規化後1〜100文字
- 読み: 1〜200文字
- カテゴリ・投稿者名: 0〜50文字
- 制御文字・不可視文字 (ゼロ幅スペース、書字方向制御など) は拒否
- 正規表現による登録は非対応 (単純置換のみ)

## セキュリティ上の前提

- スプレッドシート本体は非公開のまま。公開されるのはGASウェブアプリの応答だけです。
- ウェブアプリURLは配布物に含まれるため秘密ではありません。誰でもPOSTできますが、承認されるまで辞書には載りません。
- 投稿の同時書き込みは `LockService` で直列化しています。
- 無料アカウントのGAS実行時間は1日合計約90分です。利用者が増えて取得が多い場合は、`DICTIONARY_CACHE_SECONDS` を延ばすか、`dictionary` シートの「ウェブに公開」(CSV) への切り替えを検討してください。
